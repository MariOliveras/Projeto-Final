# 📋 Gerenciador de Tarefas em Python-Projeto-Final

Este é um projeto prático desenvolvido para consolidar conceitos de Programação Orientada a Objetos (POO), persistência de dados em arquivos JSON e manipulação de fluxos em Python.

## 🚀 Funcionalidades

- **Cadastrar tarefas** com título e descrição.
- **Listar tarefas** existentes mostrando o status atual (Pendente/Concluído).
- **Concluir tarefas** alterando o estado visual do item de forma dinâmica.
- **Remover tarefas** e reorganizar automaticamente o índice de IDs.
- **Persistência local** que salva os dados automaticamente em um arquivo `tasks.json`.

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- **JSON Library** (Nativa do Python)
